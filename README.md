# How to Process Documents with Docling

This notebook provides a step-by-step guide through creating the process to ingest PDFs or MS Word documents into Docling and converts them into a structured JSON format.

Before you begin, make sure you have Docling installed. You can install it using `pip`:
pip install docling

```bash

```
